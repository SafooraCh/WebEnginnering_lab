# Web Engineering Lab 04

Completed starter project for Flexbox, CSS Grid, ES modules, DOM manipulation, event delegation, async/await, closures, and the JavaScript event loop.

## Run

1. Extract the ZIP.
2. Open the `web_engineering_lab04` folder in VS Code.
3. Start Live Server from `index.html`.
4. Do not open the page directly with `file://`; ES modules require an HTTP server.

## Included files

- `index.html` — accessible page, office-hours table, booking controls, and feedback form
- `public/styles.css` — Flexbox, Grid, responsive media query, and selected-row styling
- `public/main.js` — delegated booking handler with async confirmation
- `public/utils.js` — exported `delay` and `makeCounter` functions
- `public/script.js` — feedback form interaction
- `NOTES.md` — event-loop prediction and explanations for Task 10
